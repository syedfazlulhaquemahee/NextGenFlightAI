How markup works

  1. Customer pays: base fare + markup
  2. Platform collects the full amount from the customer
  3. Platform pays the airline via Duffel (base fare only)
  4. Of the markup: platform profit + agency earnings split per tier rule
  5. Tiers are matched by base fare range — highest matching min wins
  6. Fallback applies when no tier matches the base fare
